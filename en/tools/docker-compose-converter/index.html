About Docker Run to Compose

        
Parse a docker run command and generate modern Docker Compose YAML for common runtime options. Processing happens locally in your browser, and the tool does not upload the entered content.

        
Privacy and compatibility

        
Results depend on browser capabilities and the supplied input. Review generated output before using it in production or formal documents.

关于 CSS 长度单位探索器

CSS 提供了绝对单位（px、pt、pc、cm、mm、in）和相对单位（em、rem、vw、vh、vmin、vmax、ch、rlh 等）两大类尺寸体系。本工具在同一交互环境中实时换算所有常见单位：拖动基准字号与参考容器宽度滑块，即可直观对比各单位如何随根字号、元素字号和浏览器视口尺寸动态变化，所有计算均在浏览器本地完成。

常见问题

写样式时应该优先用 rem、em 还是 px？

全局字号、间距与布局令牌优先推荐 rem，它会跟随用户在浏览器中设置的根字号等比缩放，同时避免 em 多层嵌套导致的指数级放大；1px 边框、阴影偏移等无需随字号缩放的细节适合使用 px；组件内随自身字号成比例变化的内边距或图标间距适合用 em。

CSS 里的 1px 等于屏幕上的 1 个物理像素吗？

不一定。CSS 像素是视觉参考单位，在 Retina 等高分屏（devicePixelRatio 为 2 或 3）上，1 个 CSS px 会映射为 2×2 或 3×3 个物理像素点，保证页面在不同像素密度的屏幕上视觉大小一致。

ch 和 rlh 单位有什么实用场景？

1ch 约等于数字“0”的宽度，非常适合限制正文阅读行宽（例如 max-width: 65ch）；1rlh 等于根元素的行高，用来设置段落间距与模块留白可以保持整页垂直韵律统一。

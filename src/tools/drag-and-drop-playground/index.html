    关于 HTML5 拖拽交互测试器

    HTML5 原生 Drag and Drop API 通过 draggable 属性与 dragstart、dragenter、dragover、dragleave、drop、dragend 一组事件协同完成元素移动、列表重排与本地文件读取。本工具将三类高频开发场景集成在同一实验面板中，配合实时时间戳事件流日志，方便前端开发者调试事件顺序与 DataTransfer 行为，文件仅在本地读取元数据，不会上传服务器。

    常见问题

    为什么绑定了 drop 事件却无法触发放置？

    浏览器默认禁止大多数元素接收拖放内容。必须同时在目标元素的 dragover（以及需要高亮反馈时的 dragenter）事件中调用 event.preventDefault()，浏览器才会允许在该容器上触发 drop 事件。

    为什么 HTML5 原生拖拽在手机触屏上不生效？

    桌面浏览器完整支持鼠标拖放，但移动端浏览器对原生 HTML5 Drag and Drop API 支持有限且手势与页面滚动冲突。如果需要在移动端实现看板或列表拖拽排序，建议结合 Pointer Events（pointerdown / pointermove / pointerup）做触屏兼容。

    拖入本工具的文件会上传到服务器吗？

    不会。案例三仅在当前浏览器标签页内读取 File 对象的名称与字节大小用于演示 DataTransfer.files，不会发起任何网络上传请求。
